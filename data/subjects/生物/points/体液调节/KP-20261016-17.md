# 血压升高的信号分子：神经递质 ＋ 血管紧张素Ⅱ

## 一句话

外周血管收缩这条通路**同时受神经和体液两条线驱动**，
信号分子是**去甲肾上腺素（神经递质）**和**血管紧张素Ⅱ（多肽类激素）**。
问「信号分子有哪些」时，**两条都要答**。

## 为什么

2026-10-12 月考 Q19 的降压反射图把三条途径画在一起：

```
紧张/惊吓/焦虑 → 交感神经兴奋
   ├─ 途径A（神经）→ 心率加快 → 心输出量↑ → 血容量↑ → 血压↑
   ├─ 途径B（体液）→ 肾素↑ → 血管紧张素原 → AngⅠ
   │                 →（血管紧张素转换酶）→ AngⅡ↑ ──┬─→ 醛固酮↑ → 血容量↑
   │                                                  └─→ 外周血管收缩 → 外周阻力↑
   └─ 途径C ──→ 外周血管收缩（交感神经直接支配血管平滑肌）
                                  ↓
                              血压升高
```

**外周血管收缩这一处，有两个来源同时作用**：

| 来源 | 信号分子 | 属于 |
|---|---|---|
| 交感神经直接支配血管平滑肌 | **去甲肾上腺素**（神经递质） | 神经调节 |
| RAAS 系统级联产物 | **血管紧张素Ⅱ** | 体液调节 |

只答一个就丢分——**这正是「神经—体液共同调节」的典型落点**。

## 易混对象

三大升压信号分子的分工：

| 物质 | 上游 | 主要作用 |
|---|---|---|
| **去甲肾上腺素** | 交感神经末梢释放 | 血管平滑肌收缩 → 外周阻力↑ |
| **血管紧张素Ⅱ** | 肾素→转换酶级联 | 血管收缩 + 刺激醛固酮分泌 |
| **醛固酮** | 肾上腺皮质 | 促进肾小管和集合管**重吸收 Na⁺和水** → 血容量↑ |

⚠️ **「重吸收」不是「泌尿」**——16(3) 红笔专门纠过这个词（见 `reference/norms.md` 的 `术语规范`）。

第二组易混——**方向相反的两条降压药靶点**（配合 KP-20261016-02 看）：

| 药类 | 靶点 | 效果 |
|---|---|---|
| ACEI（依那普利等） | 抑制**血管紧张素转换酶** | AngⅡ 生成↓ |
| **ARB（替米沙坦）** | 竞争**AngⅡ受体** | AngⅡ 作用↓ |

## 典型考法

1. 「调节外周血管收缩的信号分子有____」——答**去甲肾上腺素 + 血管紧张素Ⅱ**（2026-10-12 月考 Q19(3) 原句）
2. 「通过途径B使血容量增大，这种调节方式为____」——答**体液调节**
3. 问降压药的靶点分类——四类：利尿剂、β受体阻断剂、ACEI、ARB
4. 给药物问机理——必须落到**结合/抑制哪个靶点**，不能只写「降压」

## 来自哪道题

Q19(3)、Q19(4)（2026-10-12 月考第 II 卷第 19 题第 3、4 小问）。
红笔圈出图中「血管紧张素Ⅱ增加」与「外周血管收缩」两处，并在
Q19(4) 题干「能与血管紧张素Ⅱ受体结合」处画圈。
学生原话：「没理解调节……的信号分子」。

## 这题的价值

**高**。这是**神经与体液两条线在同一个生理指标上交汇**的位置，
考的就是「你能不能同时从两条路去想」。
只背 RAAS 而不知道交感神经也在管血管，遇到「信号分子有哪些」必然只答一半。
