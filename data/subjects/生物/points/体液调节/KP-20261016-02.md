# 降压药题：先定位作用位点，再判「生成 / 清除 / 结合」

## 一句话

药物题先在图或材料里找准**作用位点**，再判它拦的是**生成、清除还是结合**，最后才落到通路。

## 读题三步

1. **定位**：药作用在受体、转运体、酶，还是离子通道？——图上一定标了，**不要凭药名猜**。
2. **判方向**：这一环被弄成「变少 / 变多 / 被占住」？
   - 抑制**生成**（ACEI 拦 AngⅠ→Ⅱ）→ AngⅡ 变少 → 作用**变弱**
   - 抑制**清除**（SSRI 拦 5-HT 再摄取）→ 递质留得久 → 作用**变强**
   - 占据**结合**（ARB 占 AngⅡ 受体）→ 受体收不到信号 → 作用**变弱**
3. **落到通路**：血容量（少留水）、外周阻力（少收缩血管）、心输出量（降心率/收缩力）。

⚠️ 最关键的不对称：**抑制「产生」→ 作用变弱；抑制「清除」→ 作用变强。** 方向看反，整题必错。

## 为什么

血压 = 心输出量 × 外周阻力，所以只有三个下手的地方：

- 血容量↑ → 血压↑ → **少留水**
- 外周阻力↑ → 血压↑ → **少收缩血管**
- 心输出量↑ → 血压↑ → **降心率 / 收缩力**

## 四类药只落三个方向

| 药物类别 | 识别关键词 | 归哪条路 |
|---|---|---|
| 利尿剂 | 噻嗪类、呋塞米 | 少留水（抑制 Na⁺ 重吸收） |
| β受体阻断剂 | 洛尔 | 降心输出量（心率↓、收缩力↓） |
| ACEI | 普利 | 少收缩血管（拦 AngⅠ→Ⅱ） |
| ARB | 沙坦 | 少收缩血管（占 AngⅡ 受体） |

ACEI 与 ARB 都归「少收缩血管」，所以**四类药只落三个方向**。记药名是为了认出它在图上对应哪一处，不是为了背药理。

## 详细知识点：合并抑郁那一支

题目常补一句「该患者合并抑郁，宜选」——这是**分支判断题**，不是药理背诵题：

- 落在 **5-HT 清除**环节的药有两条路：抑制 5-HT 分解（单胺氧化酶抑制剂，卷面写作「5-HT 水解酶抑制剂」）、抑制再摄取（SSRI，靶点是 **5-HT 转运体**）
- 两者终点相同：**5-HT 在间隙里待更久 → 作用增强**，治的是抑郁这一支
- ⚠️ 这类药**不能拿来解释降压**。本题图上没有 5-HT → 血压的因果链，答题时只写「针对抑郁通路选药」，不要硬编降压机制
- 反过来也要防：问「哪些药能降压」时，把 5-HT 那两类塞进去就是错的

## 易混对象

- **抑制生成 vs 抑制清除**：前者让作用变弱（ACEI → AngⅡ↓），后者让作用变强（SSRI → 5-HT↑）。本卡唯一真正的陷阱。
- **ACEI vs ARB**：都削弱 AngⅡ 的效应，但一个**拦生成**、一个**占受体**；问「作用位点」必须分清。
- **ARB vs 醛固酮拮抗剂**：一个在受体上拦 AngⅡ，一个在下游拦醛固酮——同在「少留水/少收缩血管」线上，位点不同。

## 典型考法

1. 给血压调节图 + 若干药物，问「该药作用在图中的哪一处」→ 走三步
2. 给患者症状（含合并症）选药 → 先拆症状对应哪条通路，再看合并症走哪个分支
3. 问「为什么某药能降压」→ 必须写全「位点 → 该环节被抑制/被占 → 通路结果」
