# 下丘脑-垂体-肾上腺皮质轴（HPA 轴）

## 一句话

典型的**分级调节**：下丘脑发令 → 垂体转达 → 肾上腺皮质执行，分三级放大。

## 为什么

每一级都通过激素**促进下一级分泌**，同时高浓度会**反馈抑制**上一级，形成负反馈。

```
下丘脑 ──CRH──> 垂体 ──ACTH──> 肾上腺皮质 ──糖皮质激素──> 应激反应
  ↑                                                  │
  └──────────── 负反馈抑制 ←────────────────────────┘
```

## 易混对象

- **HPA 轴 vs RAAS**：都是级联，但一个是**激素**逐级传递，
  一个是**酶促切割 + 激素**混合。HPA 的每一级都是真激素。
- **ACTH 的名字有陷阱**：促肾上腺**皮质**激素，
  作用于皮质（分泌糖皮质激素），不是「肾上腺素」。肾上腺素是交感神经末梢释放的，不是这条轴。

## 典型考法

1. 给示意图用字母标出各部分（如 A=CRH，B=ACTH）
2. 「过程①和⑤所致的过度激活出现障碍」——考分级与负反馈哪个环节断了
3. 判断某物质的来源：是垂体分泌还是肾上腺皮质分泌
