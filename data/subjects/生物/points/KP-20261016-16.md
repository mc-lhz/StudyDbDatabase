# 5-HT 转运体在突触前膜：负责再摄取，不是「促进」

## 一句话

**5-HT 转运体**位于突触**前膜**，把突触间隙里多余的 5-HT **运回前膜内**（再摄取）。
它**减少**而非促进 5-HT 的作用——**抑制转运体 = 延长 5-HT 在间隙里的停留时间**。

## 为什么

突触传递的「终点」不是降解，而是**回收**：

```
突触小泡释放 5-HT  →  突触间隙  →  三条去路
                                   ├─ ① 突触前膜上的【5-HT 转运体】再摄取回前膜  ← 本卡重点
                                   ├─ ② 被 5-HT 水解酶分解
                                   └─ ③ 被酶破坏/扩散离开
```

**再摄取是主流去路**，所以它是抗抑郁药的经典靶点：

| 药物 | 靶点 | 机制 |
|---|---|---|
| 帕罗西汀（SSRI） | **5-HT 转运体**（**抑制剂**） | 阻断再摄取 → 间隙 5-HT↑ → 作用延长 → 抗抑郁 |
| 苯乙胺 | **5-HT 水解酶**（抑制剂） | 减少降解 → 5-HT 作用延长 |
| 槟榔十三味丸 | 降低**皮质醇**的量 | 压低 HPA 轴过度激活 |

⚠️ **共同点：三个药都是「让 5-HT 的作用变强」**——
不管阻降解还是阻断回收，终点都是延长作用时间。

## 易混对象

「释放」与「回收」方向相反，最容易看反：

| | 方向 | 位置 | 通透方向 |
|---|---|---|---|
| **胞吐释放** | 前膜 → 间隙 | 突触**前**膜内侧 | 向外 |
| **再摄取（转运体）** | 间隙 → 前膜 | 突触**前**膜上 | 向内 |

第二组：**转运体 vs 通道**

- **转运体**：载体蛋白，**逆浓度梯度**搬运，有饱和性、可被特异性抑制剂阻断
- **通道**：膜蛋白，顺电化学梯度，瞬时开放

第三组：**抑制 X 反而使 Y 增强**
转运体被抑制 → 回收减少 → 间隙 5-HT 增多 → 信号**增强**。
**这是本题最大的思维陷阱：抑制「清除」= 增强「作用」。**

## 典型考法

1. 给出突触结构图 + 5 种药物，问「可治疗抑郁症的有哪些」（2026-10-12 月考 Q18(2)，多选）
2. 问转运体位于突触前膜还是后膜——**前膜**
3. 问抑制转运体后突触间隙 5-HT 含量如何变化——**升高**
4. 判断正误：「转运体可以促进 5-HT 发挥作用」——错，转运体做的是**回收**
