# CO₂ 调节呼吸是神经调节，不是体液调节

## 一句话

CO₂ 调呼吸走完整反射弧，属**神经调节**——判类型看信号**怎么到达效应器**，不看它在哪儿。

## 为什么

判断神经调节 / 体液调节，只看**信号到达效应器的途径**：

- 有**神经纤维 / 反射弧**参与 → 神经调节
- 信号靠**体液（激素等）运输**到靶细胞 → 体液调节

CO₂ 的路径：
血液 CO₂ ↑ → 刺激延髓**化学感受器** → 传入神经 → 呼吸中枢 →
传出神经 → 呼吸肌。这条链上有完整反射弧，**判定为神经调节**。

⚠️ 陷阱在于「CO₂ 在血里、随血流走」就条件反射地判成体液调节。
**看物质在哪不重要，看它怎么到达效应器才重要。**

## 易混对象

神经调节 vs 体液调节（选必1 最常混的一组）：

| | 神经调节 | 体液调节 |
|---|---|---|
| 信号本质 | 电信号（神经冲动）/神经递质 | 激素（化学物质） |
| 传输介质 | 神经纤维 | 体液（血液、淋巴） |
| 速度 | **快**（毫秒级） | 慢 |
| 作用范围 | **准确、局限** | 广泛 |
| 是否一定有反射弧 | **是** | 否 |
| 本卷实例 | CO₂→呼吸中枢→呼吸肌；心率加快 | 肾素→AngⅡ→醛固酮→血容量 |

**一句话判据**：题干里只要出现「传入/传出神经」「反射中枢」「神经纤维」，
就基本判神经调节；出现「激素」「受体」「血管运输」才考虑体液调节。

## 典型考法

1. 「体液中 CO₂ 浓度的变化对呼吸运动的调节属于体液调节」——**判错**（2026-10-12 月考 Q4 原句）
2. 「人在紧张时心率加快」——判**神经调节**（交感神经兴奋，属途径A）
3. 「激素通过体液运输到全身各处」——体液调节作用范围**广泛**
4. 比较两类调节的**速度**与**作用范围**——快/准 vs 慢/广
