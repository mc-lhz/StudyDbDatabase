# 生物节律中枢在下丘脑，不在脑干

## 一句话

睡眠—觉醒、体温、血糖等**周期性节律的中枢在下丘脑**；
脑干管的是**呼吸和心跳的节律性**，两者位置不同，别互串。

## 为什么

「中枢」定位必须按功能记，不能按「都是节律」笼统归给脑干：

| 节律类型 | 中枢 | 关键点 |
|---|---|---|
| 睡眠—觉醒节律 | **下丘脑** | 熬夜 / 日夜颠倒打乱的就是它 |
| 体温日周期 | **下丘脑** | |
| 血糖日周期 | **下丘脑** | |
| **呼吸**节律 | **脑干**（延髓、脑桥） | 唯一有**自主节律性**的 |
| **心跳** | **心脏**本身 | 窦房结起搏，不靠脑干 |

⚠️ 「脑干是生命中枢」这句话本身没错，
错在**把它当成所有生命节律的总管**。
题干一出现「熬夜」「日夜颠倒」「作息」，中枢就指向**下丘脑**。

## 易混对象

三个最容易串的中枢：

| 概念 | 归属 | 记忆钩子 |
|---|---|---|
| 生物节律中枢 | **下丘脑** | 「节律找下丘」 |
| 呼吸中枢 | **脑干** | 「呼吸找脑干」 |
| 感觉（痛觉、视觉、听觉）形成 | **大脑皮层** | 「感觉找皮层」 |
| 体温调节中枢 | **下丘脑** | 「体温也归下丘」 |

第二组易混：**中枢 ≠ 产生感觉的部位**。
下丘脑是体温/节律的**调节中枢**，但「冷觉、 热觉」在大脑皮层**形成**。

## 典型考法

1. 「日夜颠倒会使脑干控制的生物节律紊乱」——**判错**（2026-10-12 月考 Q7 原句，答案即此项）
2. 「下丘脑是体温调节中枢，所以冷觉产生于下丘脑」——错，冷觉在大脑皮层
3. 「脑干中有呼吸中枢和体温调节中枢」——错，体温调节中枢在下丘脑
