# Q16(3) Ⅱ过程表示___；图丙中④处的细胞所生活的环境为___

## 我的错解

① Ⅱ过程写成了「**泌尿**」；
② ④处细胞的环境只写了一个，没意识到是**双重**的。
学生原话：「重吸收写泌尿，不知道要写重吸收，所处环境是双重的」。

## 正解思路

**红笔第一处直接写了「重吸收」**。图乙是人体内细胞与外界环境物质交换的过程，
B 是肾脏，A 是消化道，C 是皮肤，Ⅱ 是肾脏方向的箭头：

- **肾小管和集合管把原尿中有用的物质重新吸收回血液 → 重吸收**
- 「泌尿」指的是把代谢废物排出体外，是**排出去**，
  而Ⅱ问的是**收回来**，方向正好相反。

**④处是毛细淋巴管**，管壁细胞一面接触淋巴液、一面接触组织液，
所以它生活的环境是**组织液和淋巴液**——**两个都要写**。

```
毛细淋巴管壁细胞
  ├── 内侧：淋巴液
  └── 外侧：组织液
```

## 一句话教训

**「重吸收」是往回收，「泌尿」是往外排——方向先定，再选词。**
毛细淋巴管壁细胞的环境永远是**两个**。
