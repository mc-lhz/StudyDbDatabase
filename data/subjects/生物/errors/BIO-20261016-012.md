# Q17(4) 药物 X 的作用位点是在神经纤维上还是两个神经元之间

## 我的错解

写成了「药物 X 作用于神经纤维上」／「作用于两个神经元之间」，
**漏掉了「只能」**。学生原话：「没写只能，属于答题规范」。

## 正解思路

红笔在两处「说明 ___」的空上写的都是「**只能**阻断」。

题目的实验设计逻辑：

- 药物 X 的影响**不能及时消除** → 两个处理必须**在不同材料上**分别做
- 若①处理后不收缩、②处理后收缩 → 药物 X **只能**阻断神经元之间的传递
- 若①收缩、②不收缩 → 药物 X **只能**阻断兴奋在神经纤维上的传导
- 若都不收缩 → 两种位点都能阻断（**且**字一个都不能漏）

**位置对应**：图中 C/D/E 在传入神经纤维上，
虚框内两个神经元及其连接处是**突触**，A 在传出神经元胞体处。

## 一句话教训

实验结论句式固定为「药物 X **只能**阻断……」，
「只能 / 都 / 全部」这类限定词**漏一个就整句不成立**。

## 这题的价值

**高**。属 `会但粗心` ——实验逻辑你推得出来，**输在限定词上**。
`causes.md` 明确写了：这类错因**最危险**，因为它会伪装成「我会了」。
补救方式是**每次写完结论句回读一遍限定词**，而不是重做实验题。
