# Q20(2) 禁食状态下血糖的来源有___；禁食时胰高血糖素水平较高的原因是___

## 我的错解

问「来源有几条」只写了最熟的一条（肝糖原分解），没列全；
原因部分只写「血糖低 → 胰高血糖素增加」，没写反馈路径。
学生原话：「原因部分胰高血糖素反馈调节路径不明」。

## 正解思路

**第一空**（红笔补全为「肝糖原的分解／氨基酸的释放／脂肪…」）——三个来源：

| 来源 | 具体 |
|---|---|
| ① **肝糖原分解** | 肝糖原 → 葡萄糖 |
| ② **非糖物质转化** | 脂肪分解的甘油、氨基酸等 → 葡萄糖 |
| ③ **食物中糖类的消化吸收** | ⚠️ **禁食状态下这一条基本没有** |

⚠️ 禁食时只能靠 ① 和 ②；正常进食时三条都有。

**第二空**——反馈路径要写完整，因果不能断：

```
禁食 → 食物中糖类消化吸收减少
     → 血糖浓度降低
     → 下丘脑某个感受器感知（血糖变化）
     → 胰岛A细胞（α 细胞）分泌胰高血糖素【增加】
     → 促进肝糖原分解、非糖物质转化
     → 血糖升高、恢复正常
```

红笔在该空旁写「**刺激**」——提醒必须点出**是谁刺激谁**。

## 一句话教训

**问「来源」默认列全三条再按情境删减；
问「原因」必须从刺激物一路写到结果，中间环节一个不能跳。**

## 这题的价值
