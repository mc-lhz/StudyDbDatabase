# Q20(3) 模型鼠 P-/- 禁食状态下胰高血糖素相对水平___

## 我的错解

只写「低」，没写**和谁比**。学生原话：「模型鼠组别没写（学科素养、答题规范）」。

## 正解思路

原题：研究人员提出「蛋白 P 是激素 H 的受体」，依据是——
模型鼠 P-/- 可分泌激素 H，但**禁食状态下**胰高血糖素相对水平 ___。

从柱状图读：

| 组 | 正常饲喂 | 禁食 |
|---|---|---|
| 野生型鼠 | 低 | **最高** |
| 模型鼠 H-/- | 低 | 中 |
| 模型鼠 P-/- | 低 | 中（**低于野生型**） |

所以要填「**较野生型鼠低**」／「**相对较低**」。

⚠️ **注意这里的陷阱**：模型鼠 P-/- 禁食时其实**仍然比正常饲喂时高**。
只写「低」会被读成「低水平」，与图不符；
写成「较野生型鼠低」才是**有比较对象**的正确表述。

**推理链**（为什么这能作为「P 是受体」的依据）：

```
H-/- 鼠  → 不产生激素 H → 胰高血糖素【介于】野生型与正常之间（缺少 H 的部分作用）
P-/- 鼠  → 能产生激素 H  → 但胰高血糖素仍低于野生型
         → 说明 H 起了作用却没有效果 → 缺的是「H 作用的接收端」→ P 就是 H 的受体
```

## 一句话教训

**实验题的空只要出现比较级（「较」「低于」「高于」），答案里就必须写出比较对象。**
不然「低」是个没有坐标系的词。

## 这题的价值

**高**。判成 `会但粗心` + `指向明确`——
推理你做出来了（这才是真本事），输在**最后一步没写全比较对象**。
这类丢分在难题上尤其可惜：过程分拿到了，就差这一句。
