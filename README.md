## ⚠️ 这个仓库是公开的：脱敏后照常推送

远端：`https://github.com/mc-lhz/StudyDbDatabase`（Public）

**入库的是**：知识点卡、错题证据、考法分析。
**永不上传的**：`data/inbox/` 原始卷子照片（含水印、考号、姓名）——保持 gitignore。

**入库前必须去掉**：真实校名、命题/审核教师姓名、考号。
现在档案里一律写「某中学」。

⚠️ **git 历史不可逆**：脱敏必须在**第一次 commit 之前**做完，
不能靠「先推后改」——删掉文件不等于删掉历史对象。

本地 git 仍然当**时间机器**用：

```bash
# 看一张卡的完整修改史
git log -p --follow "data/subjects/生物/points/内环境与稳态/KP-20261016-09.md"

# 看某个月所有录入
git log --since="2026-10-01" --stat
```

## 目录结构

```
data/subjects/生物/
├── exams/      一次考试一份档案
├── points/     知识资产库，按【章】分文件夹    ← 唯一真源，只改这里
│   ├── 内环境与稳态/   4 张
│   ├── 神经调节/       6 张
│   └── 体液调节/       9 张
├── assets/     图片，命名 {id}-{NN}.ext
└── indexes/    派生索引              ← 全脚本重建，禁止手工编辑
```

一张卡 = 知识点 + 可挂载的错题证据（`## 错题证据` 区段）。
**不再有独立的 `errors/`**：错题不单独成文件，而是作为证据挂在知识点上。
见工具仓 `MEMORY.md` 决策 1.13。

`indexes/` 下的文件由重建脚本全量生成。
**手工改它们没有任何意义**——下次重建会被覆盖，而且状态会漂移。

## 当前有 19 张知识点卡

第一份真实卷子（2026-10-12 月考）已产出 19 张卡，覆盖内环境与稳态、
神经调节、体液调节三章。

对 AI 说「今天生物做了第三章，选择题错两道……」就会往 `points/` 里落卡。

**每次录入后 AI 都会请你复核一遍**——
因为 AI 生成的错因判断和标准答案会错，
生物术语错一个字（`线粒体基质` 写成 `线粒体基质胶`）照着背就是学错东西，比不学更糟。
复核之前，这些卡不计入统计、不进复习队列。
